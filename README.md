# Dockerized Python Application with CI/CD

## Overview
A simple Python application packaged with Docker and integrated
with GitHub Actions for automated testing and Docker image building.

## Technologies
- Python 3.12
- Docker
- GitHub Actions
- Python unittest
- Git and GitHub

## Features
- Python application with an addition function
- Automated unit tests
- Docker image build
- CI pipeline triggered by pushes and pull requests

## Run locally

```bash
python3 app.py
